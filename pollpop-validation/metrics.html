How to read this (also in README)

  1. Seed 12–15 group chats with poll links (poll.html?id=fit-check etc. or p/fit-check.html for OG). Each poll_view + vote + cta_view/cta_click is tracked.
  2. Primary metric: CTR = cta_clicks / unique_voters (unique_voters = distinct voter_ids that voted). This is the “Create your own poll — 15s →” click rate.
  3. Read verdict above after 7 days or ~30+ voters. ≥0.08 PASS, 0.03–0.08 RETRY, <0.03 KILL.
  4. Console: PollPopAnalytics.computeMetrics() and PollPopAnalytics.getEvents() / export JSON button.
